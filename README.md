# 电池文献周刊

[打开网站](https://yunkaixuchon-del.github.io/battery-weekly/)

收录以质量和相关度为先，新一期最多 60 篇，近期列表最多 100 篇。关注电池、水系、电化学储能、电池 AI 与材料设计、寿命预测与健康评估。入选文章中，正刊和重点子刊优先显示。

排除电催化、光催化、介电及铁电电容储能。条目展示作者、中文解读及其依据；已核实的公开全文可跳转到出版方或仓储在线阅读。

此仓库仅发布静态网页与展示数据。采集和更新由原电脑的 Codex 每周任务执行，GitHub Pages 负责公开托管；没有把本地更新程序移到 GitHub Actions。

基于 [Paper Firehose](https://github.com/zrbyte/paper-firehose) 扩展，保留 MIT 许可。论文内容权利归对应出版方及作者所有。
