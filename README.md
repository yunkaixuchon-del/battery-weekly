# 电池文献周刊

[打开网站](https://yunkaixuchon-del.github.io/battery-paper-weekly-site/)

近期保留 100 篇最相关文献，每周精选 50–100 篇；不足时不凑数。关注电池、水系、电化学储能、寿命预测与健康评估。入选文章中，正刊和重点子刊优先显示。

排除电催化、光催化、介电及铁电电容储能。首页展示作者、中文简介和依据摘要整理的研究示意图。

此仓库仅发布静态网页与展示数据。采集和更新由原电脑的 Codex 每周任务执行，GitHub Pages 负责公开托管；没有把本地更新程序移到 GitHub Actions。

基于 [Paper Firehose](https://github.com/zrbyte/paper-firehose) 扩展，保留 MIT 许可。论文内容权利归对应出版方及作者所有。
